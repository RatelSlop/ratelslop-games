RatelSlop Pocket

Six simplified games in one offline Python launcher for NumWorks N0120.

Download calculator edition

Python script · Installation and controls · Checksum

  1. Unzip the download.
  2. Use the NumWorks Python workshop to transfer ratelslop.py by USB. It uses one script slot.
  3. Open Python → shell on the calculator and enter from ratelslop import *, then main().
  4. Disconnect USB and play offline.

Arrows select or move. OK/EXE plays. DEL returns to the menu. ALPHA pauses.

Includes De Achterkamers, BouncyKoen, ConciergeDienst, UAVPilot, De Laatste Les and AH Gennep.

Drawn 2D calculator adaptations, without browser 3D assets or MP3 audio. Targets stock Epsilon 25.2.0 APIs; checked in the official 26.3.0 emulator. Physical N0120 testing remains unverified. No firmware changes required.
