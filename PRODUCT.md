# RatelSlop Games
Browser game launcher for RatelSlop's BouncyKoen, ConciergeDienst, UAVPilot and SchoolControl. Games play inside the launcher. Dark theme is default; a persisted light theme is available. Public builds are bundled; SchoolControl is a Dutch school adventure with a private repository and remains unavailable until the user supplies access or a playable build.

Each game has a shareable `#game/<id>` page with cover illustration, premise, availability, controls, repository link and related games. Available builds launch at `#play/<id>` in a nearly viewport-sized player, with Back to game, restart and fullscreen controls. Direct links and browser history are supported. Search, genre filters, favorites and recently played games are browser-local features. No account or server is required.
